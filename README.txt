=============================================================================
UK LEVEL 3 COMPUTING ASSIGNMENT SPECIFICATION: BRITISH BROADCASTING CORPORATION
=============================================================================

This ZIP archive contains the complete standalone web specification and working
offline website for British Broadcasting Corporation.

FILES INCLUDED IN THIS PACKAGE:
1. index.html
   A complete, single-file interactive website for BBC.
   You do NOT need Node.js, npm, or any web server to view this.
   Simply double-click 'index.html' on any computer to open it in Chrome, Edge, Safari, or Firefox!
   Features working page tabs, interactive enquiry forms, architecture diagrams, and cybersecurity matrices.

2. 01_Organisation_Profile.md
   Statutory basis, Royal Charters/Acts, regulator oversight, and digital strategy.

3. 02_Digital_Services_Catalogue.md
   Catalogue of digital services, audience demographics, and frontend/API delivery.

4. 03_Web_Architecture_Level_3.md
   Comprehensive analysis of HTML5, CSS3, JavaScript, REST/GraphQL APIs, CMS,
   Databases, Cloud/Kubernetes hosting, CDN caching, TLS 1.3, Auth, and Disaster Recovery.

5. 04_Cybersecurity_Risk_Assessment.md
   Evaluation of Phishing, Malware/Ransomware, XSS/SQLi, Credential Stuffing,
   and legal mapping to Computer Misuse Act 1990 and Data Protection Act 2018 (UK GDPR).

6. 05_Interactive_User_Flow.md
   Step-by-step UX flowchart with actor mapping and API telemetry.

7. 06_Site_Map_Hierarchy.md
   Hierarchical tree structure of site URLs and navigation tokens.

8. data_specification.json
   Machine-readable JSON export of all technical criteria.

SUGGESTION FOR SUBMITTING TO TEACHER:
- You can submit this whole ZIP archive directly.
- Or copy the Markdown files directly into your Microsoft Word or Google Docs report.
- The 'index.html' demonstrates an active, client-side prototype of the specified web service.
